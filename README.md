Sammelbot v3.1.2
=================

Der Bot sucht in der Ehrenhalle nach fehlenden Items. Wird kein Fehlendes Item gefunden, so geht zu dem nächsten Gegner einen Rang höher,
bis er ein fehlendes Item findet. Ist dies der Fall wird dieser Gegner angegriffen und das fehlende Item wird ins Sammelalbum eingetragen.
So arbeitet der Bot sich seinen Weg nach oben in der Ehrenhalle.

1. ZIP entpacken
2. Sammelbot.exe starten.
3. In Shakes & Fidget die Ehrenhalle öffnen und gewünschten Rang eingeben.
4. Den Bereich mit den gegnerischen Items auswählen.
5. Spiel-Fenster erkennen und den Angriffstimer korrekt setzen.
6. Start drücken.

Das Auswählen des Bereiches der Items ist nur beim ersten Start des des Programmes oder wenn der Bereich sich ändert benötigt.

Hotkeys:
F8 = Start / Pause / Weiter
F9 = Stop
F7 = geparkten Treffer verwerfen

Wichtige Schalter:
- Nur kostenlose Angriffe: AN empfohlen; AUS kann Pilze verbrauchen.
- Während Cooldown weitersuchen: AN durchsucht Gegner weiter bis zu einem bestätigten Treffer.

Alle Bildanalysen erfolgen lokal. Es gibt keine Telemetrie.

Anzeige: Sammelbot passt die UI automatisch an den Monitor an, auf den das Fenster verschoben wird.

Dieses Bot ist ein inoffizielles Tool und nicht mit Shakes & Fidget bzw. Playa Games verbunden.
Eine Automation wie diese hier kann gegen die Nutzungsrechte verstoßen und von Playa Games geahndet werden.
