Sammelbot v3.1.2
=================

1. Sammelbot.exe starten.
2. In Shakes & Fidget die Ehrenhalle öffnen.
3. Den Bereich mit den gegnerischen Items auswählen.
4. Spiel-Fenster erkennen und den Angriffstimer korrekt setzen.
5. Start drücken.

Das Auswählen des Bereiches der Items ist nur beim ersten Start des des Programmes oder wenn der Bereich sich ändert benötigt.

Hotkeys:
F8 = Start / Pause / Weiter
F9 = Stop
F7 = geparkten Treffer verwerfen

Wichtige Schalter:
- Nur kostenlose Angriffe: AN empfohlen; AUS kann Pilze verbrauchen.
- Während Cooldown weitersuchen: AN durchsucht Gegner weiter bis zu einem bestätigten Treffer.

Alle Bildanalysen erfolgen lokal. Es gibt keine Telemetrie.

Anzeige: Sammelbot passt die UI automatisch an den Monitor an, auf den das Fenster verschoben wird.
